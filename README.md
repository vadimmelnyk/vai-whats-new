# Оновлення зі світу AI

щотижнева нотатка про те, що в AI справді працює, де підступ і що з цим робити — VADYM.AI.

Кожен випуск лежить у [`notes/`](notes/) окремим файлом: `YYYY-Www.md`.
Відкривай файл, щоб прочитати, або тисни **Raw**, щоб забрати чистий markdown.

Публікується автоматично щотижня з [ai-ops-hub](https://github.com/vadimmelnyk/ai-ops-hub).
